# Website Daftar Kegiatan Mahasiswa

Project latihan sederhana HTML, CSS, dan JavaScript.

## Cara menjalankan
1. Buka file `index.html` melalui browser.
2. Ketik nama kegiatan pada kolom input.
3. Tekan tombol **Tambah Kegiatan**.
4. Tekan tombol **Hapus** untuk menghapus kegiatan.
5. Tekan **Mode Gelap** untuk mengganti tampilan.

## Isi folder
- `index.html` : struktur halaman website.
- `style.css` : pengaturan tampilan website.
- `script.js` : fungsi dan interaksi JavaScript.

## Catatan belajar
- `addEventListener()` digunakan untuk menjalankan kode saat ada event.
- `createElement()` digunakan untuk membuat elemen HTML melalui JavaScript.
- `appendChild()` digunakan untuk memasukkan elemen ke halaman.
- `remove()` digunakan untuk menghapus elemen.
- `classList.toggle()` digunakan untuk mengganti mode tampilan.
